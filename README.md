### 🩸 Doevida - Plataforma de Doação de Sangue

Uma aplicação web full-stack desenvolvida para facilitar a conexão entre doadores de sangue e hemocentros, com o objetivo de otimizar o processo de agendamento e gerenciamento de campanhas.

* **Tecnologias:** React.js, Node.js, Express, PostgreSQL, JWT, Tailwind CSS.
* **Status:** Em desenvolvimento.
